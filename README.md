## 📌 About the Project

**Skilled Swap Marketplace** is a full-stack, peer-to-peer skill-sharing
web application. It is designed to help people exchange knowledge by
connecting users who have skills to teach with users who want to learn.

Rather than making every learning interaction a paid transaction, the
platform encourages users to exchange their knowledge and abilities with
one another.

### 💡 Example

-   A developer can teach **Web Development** while learning **Graphic
    Design**.
-   A designer can teach **Photoshop** while learning **JavaScript**.
-   A photographer can teach **Photography** while learning **Video
    Editing**.
-   A musician can teach **Music** while learning another creative
    skill.

### What Users Can Do

-   Create an account and manage a personal profile.
-   Add skills they can teach and skills they want to learn.
-   Discover other users and explore skill opportunities.
-   Find compatible skill partners.
-   Send and manage skill-swap requests.
-   Communicate with other users through messaging.
-   Submit reports and feedback to the platform.
-   Manage account settings and profile information.

------------------------------------------------------------------------

## 🎯 Problem Statement

Many people have useful skills but may not know where to find others who
can help them learn something new. Traditional learning options can
involve paid courses, tutors, training programs, or separate platforms.

Skilled Swap Marketplace aims to make peer-to-peer learning easier by
providing one place where users can present their skills, discover
potential learning partners, and arrange knowledge exchanges.

## 🔄 How It Works

1.  **Register** --- Create an account on the platform.
2.  **Create Your Profile** --- Add your personal information and
    introduce yourself.
3.  **Add Your Skills** --- List the skills you can teach and the skills
    you want to learn.
4.  **Discover Users** --- Explore other users and their skills.
5.  **Find a Match** --- Look for people whose skills complement your
    learning goals.
6.  **Send a Swap Request** --- Propose a skill exchange to another
    user.
7.  **Manage the Request** --- The receiving user can respond to the
    request.
8.  **Connect and Exchange** --- After a request is accepted, users can
    communicate and arrange their knowledge exchange.

## 🏗️ System Architecture

The application uses a client-server architecture. The frontend sends
requests to PHP endpoints, and the backend communicates with the MySQL
database through PDO.

### Architecture Layers

``` text
User
  |
  v
Frontend
HTML + CSS + JavaScript
  |
  v
Fetch API / HTTP Requests
  |
  v
PHP Application
Pages + API Endpoints + Business Logic
  |
  v
PDO
  |
  v
MySQL Database
```

### General Data Flow

``` text
User Action
    |
    v
JavaScript
    |
    v
Fetch API
    |
    v
PHP API Endpoint
    |
    v
PDO
    |
    v
MySQL
    |
    v
PHP Response (JSON)
    |
    v
JavaScript UI Update
```

This allows supported frontend operations to communicate with the
backend asynchronously without requiring a complete page reload for
every action.

## 🗄️ Database

The application uses **MySQL** for data storage and **PHP Data Objects
(PDO)** for database interaction.

The database supports information related to:

-   Users and account information
-   Skills and user-skill relationships
-   Swap requests
-   Messages and conversations
-   Notifications
-   Reports and other application activity

### Database Concepts Used

-   Primary keys
-   Foreign keys
-   Unique identifiers
-   Relational database structure
-   Prepared statements
-   PDO database connections

Prepared statements are used with PDO to help protect database queries
against SQL injection when implemented correctly.

The SQL database file is located in the `database/` directory.

------------------------------------------------------------------------

## 🔌 API and Fetch API

The application uses JavaScript's **Fetch API** to communicate
asynchronously with PHP backend endpoints.

This allows supported parts of the interface to exchange data with the
server without requiring a complete page reload.

### General Request Flow

``` text
User Action → JavaScript → Fetch API → PHP Endpoint
→ PDO → MySQL → PHP Response → JSON → UI Update
```

### Example

``` javascript
fetch("api/example.php", {
    method: "POST",
    body: formData
})
.then(response => response.json())
.then(data => {
    // Handle the response and update the interface
});
```

This is a simplified example of the request pattern. Actual endpoints
may use different methods, request data, and response formats.

## 🚀 Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

Install the following:

-   [XAMPP](https://www.apachefriends.org/)
-   PHP 8.x
-   MySQL
-   Apache
-   Git
-   A modern web browser

### 1. Clone the Repository

Open a terminal and run:

``` bash
git clone https://github.com/Kushal0789/Skilled-swap-marketplace.git
cd Skilled-swap-marketplace
```

### 2. Move the Project to XAMPP

Move or copy the project folder into:

``` text
C:\xampp\htdocs\
```

The resulting project path should look like:

``` text
C:\xampp\htdocs\Skilled-swap-marketplace\
```

### 3. Start XAMPP

Open the XAMPP Control Panel and start:

-   Apache
-   MySQL

### 4. Create and Import the Database

1.  Open [phpMyAdmin](http://localhost/phpmyadmin).
2.  Create the database required by the project.
3.  Select the new database.
4.  Import the SQL file from the project's `database/` directory.

Use the database name and SQL file expected by the project's current
configuration.

### 5. Configure the Database Connection

Open the database configuration file in the `config/` directory and
update the connection details for your local environment.

A typical local XAMPP setup may use:

  Setting    Example
  ---------- ----------------------------------------------------
  Host       `localhost`
  Username   `root`
  Password   Empty by default in many local XAMPP installations
  Database   The database name you created/imported

Use the credentials configured on your own machine. Do not publish real
passwords or private credentials in the repository.

### 6. Run the Project

Open the following address in your browser:

``` text
http://localhost/Skilled-swap-marketplace/
```

The application should now load from your local XAMPP server.
