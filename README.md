# Skilled Swap Marketplace 🤝

A peer-to-peer skill-swapping web application built with pure PHP, MySQL, and vanilla JavaScript. The platform allows users to share their expertise, discover skill matches, send swap proposals, and message each other directly.

---

## 🌟 Key Features

- **User Authentication**: Secure user registration, login, and session management with password hashing.
- **Matchmaking Engine**: Finds compatible users based on skills offered and skills requested.
- **Swap Proposal System**: Send, accept, or decline swap requests with real-time status updates.
- **In-App Messaging**: Chat interface for matched users to coordinate learning sessions.
- **Notifications**: Automated notifications for new swap proposals and updates.
- **Admin & Moderation**: Basic administrative tools to monitor platform stats, user reports, and manage listed skills.

---

## 🛠️ Tech Stack

- **Backend**: Pure PHP 8.x, MySQL (PDO)
- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Custom CSS3
- **Version Control**: Git & GitHub
